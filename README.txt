Cara menjalankan:
1. Jalankan XAMPP, aktifkan Apache dan MySQL.
2. Buat database dengan import file db_sekolah.sql lewat phpMyAdmin.
3. Simpan semua file PHP ini di folder htdocs/praktikum_php_mysql.
4. Buka browser:
   - http://localhost/praktikum_php_mysql/login.php
   - http://localhost/praktikum_php_mysql/index.php
5. Login berhasil jika username = admin dan password = admin.
